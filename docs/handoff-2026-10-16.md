## 7. 卡住的地方（為何我無法自己建廣告組合）

透過 Meta Ads MCP 建立廣告組合，四種方式全部失敗：
1. `ads_create_ad_set` 在現有活動下：Meta 回 PERMISSION 錯誤 `EntWhatsAppBusinessCampaignCreationView ... AlwaysDenyRule`（不論有無 destination_type、product_set_id）。
2. `ads_create_ad` 內嵌 adset_spec：INTERNAL error。
3. 新建活動再建廣告組合：同樣 PERMISSION 錯誤（該活動已刪）。
4. `ads_boost_ig_post`（confirmed=true）：被執行環境的安全分類器擋下（Real-World Transactions），需使用者明確同意後再試。

另外 MCP 工具沒有「台灣通用聲明」(regional_regulated_categories: TAIWAN_UNIVERSAL) 的欄位，即使上述錯誤解掉，API 建的廣告組合也會卡這一關。
`ads_get_ad_entities` 的 draft 模式（object_state=draft）在此帳號尚未開放。
本環境沒有可操作使用者電腦的瀏覽器工具。
